# 🎯 打靶測驗 - 輕量級訓練網頁版 (Aim Trainer Lite)

這是一款使用 HTML、CSS、JavaScript 搭配 **Node.js (Express)** 打造的 **網頁版打靶訓練小遊戲**。專為喜愛 FPS 射擊遊戲（如 Apex Legends）的玩家設計，非常適合用來測試高階玻璃滑鼠墊的滑順度與精準定位手感，並內建伺服器提供「全球公開排行榜」功能！

---

## ✨ 遊戲特色

* **極簡架構，隨開即玩**：前端不依賴複雜框架，後端採用輕巧的 Express 伺服器，啟動迅速。
* **純粹的打靶體驗**：專注於單點 Flick（甩槍）與快速定位訓練，點擊後目標立即隨機重生。
* **全球排行榜系統**：
    * **即時更新**：遊戲結束後可輸入名稱上傳分數，透過 RESTful API 實時更新前 10 名神人榜。
    * **無縫銜接**：目前採用輕量化的記憶體儲存，未來可輕鬆擴充串接 SQLite 或 MongoDB 等真實資料庫。
* **倒數計時挑戰**：每局 30 秒，挑戰自己的極限反應速度與肌肉記憶。

---

## 🎮 如何遊玩

1. **啟動伺服器**：確保後端的 Node.js 伺服器已啟動。
2. **進入遊戲**：打開瀏覽器，前往 `http://localhost:3000`。
3. **開始挑戰**：點擊畫面上的「開始遊戲」，倒數計時 30 秒隨即開始！
4. **擊殺目標**：畫面上會隨機出現紅色的標靶，盡可能快速且精準地將其點掉。
5. **上傳榜單**：時間到後會結算擊殺分數，輸入你的玩家 ID 即可上傳成績，看看自己排行第幾名！

### ⌨️ 操作方式

* **打擊按鍵**：滑鼠左鍵點擊。
* **移動定位**：強烈建議搭配順手的滑鼠與優質滑鼠墊以獲得最高分數。

## 🛠️ 開發與部署指南

如果你想要在自己的電腦上運行這個專案，請按照以下步驟操作：

### 1. 環境需求與啟動

1. 請確保電腦已安裝 [Node.js](https://nodejs.org/)。
2. 在專案資料夾內開啟終端機，執行以下指令安裝依賴套件：
   ```bash
   npm install
3. 啟動遊戲伺服器：node server.js

### 2. 疑難排解 (Windows 終端機錯誤)

若在 VS Code 終端機執行 npm 時遇到「無法載入 npm.ps1」的紅色權限錯誤：

**解法 A（推薦）**：以系統管理員身分開啟 PowerShell，輸入 Set-ExecutionPolicy RemoteSigned，按 Y 確認後，重開終端機。

**解法 B**：將終端機從 PowerShell 切換為傳統的 Command Prompt (cmd) 即可正常執行。

## 📁 檔案結構

server.js：後端核心邏輯，包含 Express 伺服器設定與排行榜 API 路由。

package.json：專案的身分證，記錄依賴套件 (Express) 與執行指令。

public/index.html：包含所有的 HTML 架構、CSS 樣式設計與前端遊戲邏輯 (JavaScript)。
