# WP期末作業總攬

本專案包含了網頁設計課程的作業與實作練習，內容涵蓋從基礎的前端網頁切版 (HTML/CSS)、JavaScript 核心邏輯，一直到後端 Node.js (Express 框架) 的基礎伺服器架設。

## 📂 專案目錄結構與說明

以下為本專案的各個學習模組與作業內容說明：

* **[01-自我介紹](./01)**
    * **內容：** 個人自我介紹網頁。
    * **重點：** 基礎 HTML 標籤應用、CSS 樣式設計與基礎排版。

* **[02-表單](./02)**
    * **內容：** 網頁互動表單 (Forms) 的設計與實作。
    * **重點：** 各式 Input 元件的運用、資料驗證基礎、表單 UI 設計。

* **[03-Hello](./03)**
    * **內容：** 環境建置與基礎測試。
    * **重點：** 確認執行環境與基礎語法的 `Hello World` 運作。

* **[04-JS基礎題](./04)**
    * **內容：** JavaScript 程式語言的基礎邏輯練習題。
    * **重點：** 變數宣告、迴圈控制、陣列操作、函式 (Function) 等核心演算法觀念。

* **[06-Callback練習](./06)**
    * **內容：** JavaScript 非同步處理 (Asynchronous) 的實作練習。
    * **重點：** 回呼函式 (Callback Function) 的使用方式與非同步執行順序的理解。

* **[07-Express基礎](./07)**
    * **內容：** 使用 Node.js 與 Express.js 框架建立基礎後端伺服器。
    * **重點：** 伺服器建置、路由 (Routing) 設定、基礎 HTTP 請求處理 (GET/POST)。

## 💡 期中專案簡介 

**[期中專案](./aim-trainer)**

這是一個專為 FPS 射擊遊戲玩家設計的打靶小遊戲。主要特色在於純粹的 Flick（甩槍）訓練與精準定位測試，並透過 Node.js (Express) 實作了 RESTful API 來處理排行榜資料。本專案不依賴龐大的前端框架，非常適合用來展示網頁 DOM 操作、全端互動邏輯與 API 串接的基礎實作能力。

## 🚀 核心功能 (Features)

* **純粹的打靶體驗**：專注於單點快速定位，點擊目標後隨機重生，每局 30 秒極限挑戰。
* **全球公開排行榜**：遊戲結束後可上傳分數，透過 API 即時更新並讀取前 10 名玩家榜單。
* **極簡輕量架構**：前端純手寫，後端採用記憶體儲存，啟動迅速且易於未來擴充（如串接 SQLite/MongoDB）。

## 🛠️ 技術棧 (Tech Stack)

* **前端 (Frontend)**：HTML5, CSS3, JavaScript (Vanilla)
* **後端 (Backend)**：Node.js, Express

## 🚀 如何執行此專案

1.  **靜態網頁 (01, 02, 05)：** 可以直接使用瀏覽器開啟 `.html` 檔案，或使用編輯器（如 VS Code）的 Live Server 擴充套件啟動以獲得最佳體驗。
2.  **JavaScript 邏輯練習 (03, 04, 06)：** 建議透過 Node.js 環境在終端機執行 (輸入 `node 檔案名稱.js`)，或在瀏覽器的開發者工具 Console 中測試。
3.  **Express 後端伺服器 (07)：**
    * 請確認電腦已安裝 [Node.js](https://nodejs.org/)。
    * 開啟終端機並進入 `07-Express基礎` 資料夾。
    * 執行 `npm install` 安裝相關相依套件。
    * 執行 `node app.js` (或對應的進入點檔案) 來啟動伺服器。
