## 📂 習題章節內容

### 習題一：開發環境建置與基礎輸出入
* **撰寫目的**：熟悉 IDE 操作、專案結構，以及基礎的主機板/控制台資料輸入與輸出。
* **實作功能**：
    * 使用者名稱與基本資料輸入互動。
    * 基礎算術運算子（加、減、乘、除）實作與格式化字串輸出。
* **目錄路徑**：`./Exercises/Exercise01/`

### 習題二：控制結構與條件判斷
* **撰寫目的**：掌握條件分支語句（`if-else`、`switch-case`）的邏輯流程。
* **實作功能**：
    * 實作一個基礎的**計算機邏輯運算**，根據輸入的運算子執行對應計算並進行除以零的防錯機制。
    * 學生成績階級評等與閏年判斷系統。
* **目錄路徑**：`./Exercises/Exercise02/`

### 習題三：迴圈結構與陣列應用
* **撰寫目的**：學習重複執行結構（`for`、`while`）與一維/二維陣列的資料儲存與歷遍。
* **實作功能**：
    * 實作陣列排序演算法（如：氣泡排序法）。
    * 矩陣加法與乘法運算器。
* **目錄路徑**：`./Exercises/Exercise03/`

### 習題四：函式與物件導向基礎
* **撰寫目的**：練習將程式碼模組化，理解函式（Methods）呼叫、參數傳遞以及類別（Class）與物件（Object）的概念。
* **實作功能**：
    * 封裝重複使用的數學運算邏輯。
    * 建立簡易的物件類別（例如：學生資料類別、遊戲角色類別），並實作屬性（Properties）與方法。
* **目錄路徑**：`./Exercises/Exercise04/`

### 習題五：視窗介面與事件處理
* **撰寫目的**：從控制台（Console）轉移至圖形使用者介面（GUI），學習表單元件與事件驅動程式設計。
* **實作功能**：
    * 使用 Windows Forms / WPF 設計視覺化介面。
    * 實作按鈕點擊、文字方塊輸入改變等事件監聽。
* **目錄路徑**：`./Exercises/Exercise05/`

### 習題六：檔案輸入輸出與例外處理
* **撰寫目的**：學習如何進行本機檔案的讀寫操作，並整合 `try-catch` 機制確保程式魯棒性。
* **實作功能**：
    * 將應用程式的紀錄或設定檔以 `.txt` 或 `.csv` 格式儲存至本機。
    * 實作讀取外部檔案並解析內容，並捕捉「找不到檔案」或「格式錯誤」之例外。
* **目錄路徑**：`./Exercises/Exercise06/`

### 習題七：綜合資料結構應用
* **撰寫目的**：結合前面所學，活用動態陣列（`List`）或字典（`Dictionary`）等進階資料結構進行資料管理。
* **實作功能**：
    * 實作一個小型管理系統（如：通訊錄、待辦事項清單）。
    * 支援資料的增、刪、查、改（CRUD）功能。
* **目錄路徑**：`./Exercises/Exercise07/`

## 🚀 期中專案：互動式應用程式開發

* **專案名稱**：互動式桌面應用程式與遊戲系統
* **專案概述**：
    本專案為一個綜合性的桌面應用程式，融合了**視窗化計算工具**與**趣味互動遊戲（如：機率骰子遊戲/小遊戲）**。旨在展現物件導向設計、圖形化介面佈局（GUI Layout）以及流暢的事件觸發邏輯。
* **核心功能亮點**：
    1.  **完整 GUI 介面**：美觀的版面配置，包含豐富的控制項（Buttons, Labels, ImageBoxes 等）。
    2.  **核心邏輯演算**：精準的數值計算、亂數隨機生成演算法，並具備即時畫面更新機制。
    3.  **狀態與歷史紀錄管理**：即時顯示當前的遊戲勝率、計算歷程，並支援重設功能。
    4.  **例外與防錯機制**：全面防範不合法的輸入，避免程式崩潰，提供良好的使用者體驗。
* **專案架構圖/模組說明**：
    * `Views/`：負責視窗 UI 表單設計與刻劃。
    * `Models/`：負責底層核心邏輯、數值運算與資料結構定義。
    * `Controllers/` 或 `Events/`：負責串接介面動作與邏輯運算。
* **專案路徑**：`./MidtermProject/`
