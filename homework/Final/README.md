# Aim Trainer 🎯

這是一個基於 Node.js 建立的網頁版 Aim Trainer（射擊瞄準訓練器），幫助使用者練習滑鼠的精準度與反應速度。

## 🛠️ 環境要求 (Prerequisites)

在開始之前，請確保你的電腦已經安裝了以下環境：
* [Node.js](https://nodejs.org/) (建議使用 LTS 版本)

## 🚀 快速開始 (Getting Started)

請依照以下步驟在本地端啟動並運行此專案：

### 1. 進入專案目錄
打開終端機 (Terminal) 或命令提示字元，切換至專案所在的資料夾：
`cd aim-trainer`

> **注意：** 如果你的專案內有 `package.json` 檔案，在啟動伺服器前可能需要先執行 `npm install` 來安裝相關依賴套件。

### 2. 啟動伺服器
在終端機輸入以下指令來啟動 Node.js 伺服器：
`node server.js`

### 3. 開啟網頁
確認伺服器順利啟動後，請打開你的網頁瀏覽器（如 Chrome, Edge, Safari），並前往以下網址：
`http://localhost:3000`

現在你應該可以開始使用 Aim Trainer 了！

## 🛑 如何停止伺服器

若要關閉本地端伺服器，請回到正在執行伺服器的終端機視窗，並按下：
**`Ctrl + C`**
